# 信息图与视觉长页

加载 [frontend-design](../frontend-design/SKILL.md)。围绕一个可清楚表达的结论规划内容次序：背景、证据、机制、影响和行动，按实际资料调整，不机械套固定章节。

让每个区块采用适合信息关系的形式：趋势用图表，对比用平行结构，流程用图解，空间信息用地图或标注，原始资料用可审计来源。数量和关系来自输入，示例明确标记。

用标题与视觉锚点建立阅读顺序；结构标签只表达真实分类或步骤。内容不足时精简或合并，不靠空卡片、固定高度或装饰填充。定量图加载 [charts](../charts/SKILL.md)，数据报告加载 [data-report](../data-report/SKILL.md)。

检查长页面的分段截图、移动重排、引用、可访问性和打印需求。多图比较用于整体检查，长页的各段仍需分别查看。交付按 frontend-design 的文件发布流程执行。
