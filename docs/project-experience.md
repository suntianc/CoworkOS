项目经验保存当前项目里可复用的结论与流程，独立于[个人记忆](user-memory.md)和 Task 内已有的上下文摘要。它不修改模型参数。自动沉淀可以提出项目技能的新版本；当前验证复核已保存的实际执行证据，不会额外启动命令、沙箱实验或效果 A/B。

## 使用与管理

在已有项目的编辑窗口点击“项目经验”。三个开关分别控制“使用项目经验”“自动沉淀”“自动启用已验证经验与技能”，新项目全部默认关闭，互不隐式开启。可以仅手工维护经验，也可以开启自动沉淀、保留人工复核。关闭使用会暂停学习，保留已有内容、配置和待处理引用；暂停期间不接收新来源。

用户可新增、编辑、停用、启用、拒绝、删除经验和技能，查看来源引用与验证证据，固定版本、取消固定及回滚。手工保存立即成为启用且固定的内容；编辑候选的按钮为“编辑并接纳”，保存会发布该候选。每项最多保留八个版本，回滚创建新版本并固定，后台不再改写。手工来源即使取消固定，也不参与自动改写。关闭弹窗或切换项目保留当前页面的项目独立草稿，整页刷新不保留；版本冲突保留草稿并要求刷新核对。

每项目可保存 40 条正式经验，每条正文最多 1000 字符；20 条正式技能，每条最多 6000 字符。停用内容仍占正式容量。候选最多 30 条，30 天未更新后在下一次后台结算时过期；另外最多保留 30 条拒绝记录。来源与历史分别最多八份，不会无限增长。字符数按 JavaScript 字符串长度计算。该容量独立于个人记忆的 2000 字符预算。

## 后台沉淀

Main 运行结束后尝试持久化一个小的 Task/Run 引用，前台不为此扫描轨迹，不等待学习模型。接收失败静默跳过本次沉淀。独立 Pi CLI 仅在已开启沉淀时收集当前轮的有界工具回执，完成后以私有 `runs/<runId>/experience-evidence.json` 保存终态证据，不扫描完整历史。队列最多 30 个 Run，后台从可信 Task/Run 记录重新检查项目归属、终止状态和来源，再读取有限的运行消息、工具结果及工作摘要。临时工作区和独立文档 holding Task 不参与项目学习。个人偏好学习仍只处理用户原文；项目沉淀是独立授权的更大数据范围，可能把过滤后的项目执行片段发送到当前模型连接。

常驻宿主启动后检查一次，每 15 秒轮转检查一个项目。引用至少等待 60 秒，任一前台运行结束后也需满足共享的 60 秒安静窗。前台启动、关闭功能、修改配置或切换模型连接会取消旧轮次；已发请求仍可能计费。后台在途每 100 毫秒检查轻量投影与活动标记，提交时在锁内再次检查代次及当前状态。每轮最多 60 秒，无 SDK 自动网络重试；首次失败延迟一分钟，此后五分钟，最多自动尝试三次。额度不足与前台抢占不计失败。

后台先提炼最多三个候选，再用独立的模型请求复核证据与适用范围。引用必须逐字出现在对应来源；“任务完成”或助手自称成功不构成验证。宿主标记实际记录中成功的测试、检查或验证工具结果，再由复核请求判断这些结果是否支持候选内容。自动启用要求开关开启，且至少三个不同 Task 各自提供通过复核、具有相关成功验证的证据；同一 Task 的续跑、重试不增加独立支持次数。缺乏验证的经验可以保留为候选，由用户接纳。

模型、输出预算和小时额度按项目独立配置。模型留空沿用当前连接，关闭后台推理；单次输出 256–4096 tokens，默认 2048；每小时模型请求 2–24 次，默认 6 次，提炼和复核分别计一次，取消也计入。一次有候选的处理通常需要两次请求，因此默认额度最多容纳约三个完整轮次，不是六次沉淀成功。额度跨重启保留，调低或改模型不清空用量。各项目与个人记忆额度相互独立，总用量可累加。

后台只可演进启用、自动来源且未固定的条目，每次演进同样重新积累候选与三份独立已验证来源。手工编辑、固定、回滚、停用、拒绝或删除会使旧轮次失效，并丢弃当时待处理引用，防止旧轨迹重新覆盖操作；单纯配置切换保留引用但更新代次。精确重复和拒绝标识有界保存，不能替代完整的语义冲突识别。

## 加载与持久化

正式经验仅提供当前项目的有界参考正文。技能只提供简短目录，完整正文由原有技能发现与按需加载机制读取；候选、来源队列和版本历史不进入普通任务上下文。当前用户要求与项目规则始终优先，经验和技能不授予工具权限。上下文预算不足时省略可选内容，不为沉淀压缩用户当前输入。普通任务仍有轻量本地读写，后台 JSON 与模型工作也会消耗资源；不能保证绝对零延迟。

存储位于 `ATRIA_HOME/project-experience/<sha256(catalog-path, projectId)>/`，目录和文件分别使用私有权限 700/600。`experience.json` 为权威状态，`profile.json` 为正式经验和技能目录的轻量投影，`identity.json` 用于重启发现。拥有稳定项目 ID 时，调整项目目录不搬迁或丢失已保存经验；没有稳定 ID 的旧路径按目录哈希隔离。各 catalog 的同名 ID 不共享数据。旧目录快照对应的待学习引用可能因归属校验而跳过，已有正式经验保留。

只有启用的正式技能生成私有 `skills/<uuid>/SKILL.md`，名称带 `learned-` 前缀，不改项目 `.pi/skills/` 或 `AGENTS.md`。停用、删除或关闭使用会撤下可加载文件；候选不会发布。更新使用文件锁、版本检查及原子替换；损坏数据保留并停止加载，普通聊天可继续。备份须保护整个项目经验目录，其中包含本地明文来源片段。禁用和删除不会撤回已有模型请求、历史会话或已加载的旧正文；后续请求使用当前投影。
