# Atria 0.1.2-beta.10

本版更新应用与组件管理、模型连接、会话恢复及科学计算工具。默认 Mac 包内置 CadQuery/Python、Blender 和 PPTist 编辑器。最终来源、产物大小与 SHA-256 以本版发行清单为准。

## 安装与支持范围

- Mac 完整包：macOS 14+、Apple Silicon；包含 Agent、文件/代码工具、任务恢复和全部现有应用组件。组件在“设置 → 应用与组件”查看状态与修复说明，随 Atria 整体升级，无需用户提供组件下载凭据。
- CLI tgz：Node >=22.19.0 和 npm；安装需要网络及安装脚本，尚未发布到 npm registry。其他平台的本轮安装未验证。
- 独立 CadQuery/Python 与 PPTist 归档及 `atria-components-darwin-arm64.json` 供内部或进阶安装使用。默认 App 已内置组件。
- 科学工具默认关闭，通过启动环境变量启用；使用宿主提供的 `python3` 或显式指定的解释器，数组分析需要自行准备 NumPy/SciPy。此能力在后续版本中移除。
- 下载时核对同版本 SHA-256、来源清单、Mac 签名报告及第三方许可。仓库为私有时，仅获准访问仓库的用户可下载 Release。

## 验证与已知限制

本次发版集中执行一次完整 `npm run verify`，并分别记录浏览器、原生、DMG/CLI/组件安装和签名检查。具体结果附在发行说明的验收记录中；失败修正后仅重跑相关检查。历史候选包的结果不替代本版最终包验证。

- 另一台无开发环境 Mac 的首次安装/升级、真实模型任务、真实系统钥匙串授权允许/拒绝、录音与系统权限人工流程未完成。协议夹具与测试钥匙串不证明这些场景通过。
- 本包使用 ad-hoc 签名，未完成 Developer ID 签名、公证及 Gatekeeper 下载隔离属性验收。Intel Mac、Windows、Linux 本轮安装未验证。
- 锁屏或缺少系统权限时，原生窗口操作与屏幕观察可能跳过；跳过项按实际结果保留。
- 第三方真实缓存命中与各供应商协议分别验收；本地 Chat/Responses 协议测试不能证明真实供应商行为或模型质量。
- PPT 历史备份包含资源目录的 `history-blobs/`；降级需恢复旧版备份。升级前保留用户数据和外部原文件备份。
- 默认完整 App 不依赖独立组件下载；进阶组件安装的公网或私有认证可用性须按实际分发渠道单独验证。

## English release summary

This beta updates application/component settings, model connections, conversation recovery and optional scientific tools. The full Mac package targets Apple Silicon on macOS 14+ and bundles CadQuery/Python, Blender and PPTist. It uses ad-hoc signing, is not notarized and installs through a manually verified DMG. The CLI requires Node >=22.19.0, npm, network access and installation scripts. Private repository releases require repository access.

New connections default to Responses; legacy connections keep their protocol. Connection probes share runtime reasoning parameters and each connection can configure context capacity. Settings subpages provide consistent back/close navigation. Native file opening preserves original-file saves and repeated artifact opening reuses editable copies. Keychain retries retain the main Electron runtime and the existing ciphertext format. A transient second Dock icon during credential saves remains a known beta limitation. Eighteen optional offline scientific functions support Main/delegated runs; Python and optional NumPy/SciPy dependencies remain host-managed.

Issue #56 was classified as a local command-environment configuration matter; #74 was reverted by #76. General Python installation and aliases remain the local environment's responsibility.

Final validation evidence accompanies the release artifacts. Separate clean-Mac installation, real-model work, real Keychain authorization, recording, Developer ID signing/notarization and other-platform installations remain unverified. Skipped locked-screen or permission-dependent checks are reported separately. Back up user data and external projects before upgrading. Third-party licenses and corresponding-source files accompany the bundled components.
