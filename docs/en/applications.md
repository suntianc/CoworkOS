# Applications and files

English | [中文](../applications.md)

This branch centers on agent automation. The built-in application catalog is empty and the Applications and Load application controls are hidden. Describe the task in a conversation and attach files; agents read, modify and generate files through generic file tools and deliver outputs through the task panel.

Generic MCP, workspaces, resource revision and recovery protocols remain available for external integrations. See [capabilities and migration](builtin-capabilities.md) for removed features and existing files.
